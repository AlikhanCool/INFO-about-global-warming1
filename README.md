Telegram-бот, который выдает случайные и важные факты о глобальном потеплении и изменении климата в один клик.

## Цель проекта

Сделать информацию об глобальном потеплении максимально доступной. Вместо чтения длинных статей пользователь может зайти в telegram, нажать одну кнопку и узнать короткий, полезный факт
