# INFO-about-global-warming

> **Автор:** <AlikhanCool>  
> **Ссылка на бота:** [@FunnyBot]

Telegram-бот, который выдает случайные и важные факты о глобальном потеплении и изменении климата в один клик.

---

## Цель проекта

Сделать информацию об экологии максимально доступной. Вместо чтения длинных статей пользователь может зайти в Telegram, нажать одну кнопку и узнать короткий, но шокирующий или полезный факт о состоянии нашей планеты.
